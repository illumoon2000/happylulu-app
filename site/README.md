한영 홈의 전신 캐릭터를 제목 위에서 실제 Mac 패널 옆으로 옮겨 하나의 장면으로 묶었습니다. CSS로 유기적인 민트 배경·바닥 그림자·작은 앰버 별과 피치 점을 더했습니다. 캐릭터는 원본 비율을 유지하며 패널과 각각의 그리드 열을 사용하므로 눈·시각·패널 제목을 가리지 않습니다. 제목·설명·버전 안내는 편집 가능한 HTML이며, 장식은 `aria-hidden` 또는 빈 대체 텍스트로 중복 낭독을 피합니다. 가상 데이터·로컬 build 34.5·공개 버전 차이 안내도 보존합니다.

수정 전 텍스트 스냅샷은 checkout의 `.build/warm-site-before/`에 사이트 상대 경로로 보존했습니다. JavaScript 동작·원본 PNG·앱 소스·호스팅 설정은 바꾸지 않았습니다. 공통 캐시 키만 `macos-v1.5.18-build34-site-refresh-20261021-warm`으로 갱신했습니다. `python3 site/check-site.py`로 기존 48페이지·링크·앵커·이전 릴리즈 본문을 확인했고 `git diff --check -- site`를 통과했습니다. 이번 시각 보완은 실제 로컬 브라우저에서 대표 경로 8개 × 1280/390/320px 24조건과 한영 홈 × 650/651/719/720/800/801px 12조건, 합계 36조건을 최종 확인했으며 가로 넘침이 없었습니다. 651px에서 발견한 2px 넘침은 태블릿 민트 배경의 inset·회전 범위를 줄이고 부엉이 폭을 조정해 해결했으며 같은 경계 폭에서 재확인했습니다. 한영 320/390px도 최종 재확인했고, 첫 화면의 부엉이·앱 장면과 오전반차 13:00–17:00 선택이 유지됐습니다. 독립 증분 검토에서 조치할 결함은 없었고 대표 색상 쌍의 최소 대비는 4.63:1이었습니다. [데스크톱 홈](../../../../디자인/happylulu/2026-10-21-design-update/local-site/warm-desktop.jpg), [모바일 홈](../../../../디자인/happylulu/2026-10-21-design-update/local-site/warm-mobile.jpg), [기능 목록](../../../../디자인/happylulu/2026-10-21-design-update/local-site/warm-features.jpg), [브라우저 관찰 기록](../../../../디자인/happylulu/2026-10-21-design-update/local-site/warm-browser-qa.json)과 [로컬 결과 기록](../../../../디자인/happylulu/2026-10-21-design-update/local-site/README.md)에 결과를 남겼습니다. 위 75조건 검증은 이전 디자인의 기록이며 이번 보완의 최종 36조건과 구분합니다. 로컬 적용이며 공개 사이트는 변경하지 않았습니다.

## 페이지 구성

- `/`, `/en/`: 제품 소개, Mac1.5.19 build35·Windows1.5.13 직접 다운로드, 짧은 설치 요건·가이드 링크, 핵심 기능과 상태 체험.
- `/guide/`, `/en/guide/`: 설치·첫 실행·매일 사용·출근 수정·근무 유형·플러그인·외관·기록·업데이트·문제 해결·플랫폼 차이를 설명합니다. 사용 안내는 GitHub 문서로 넘기지 않습니다.
- `/features/`, `/en/features/`: 기능12개 목록. 목록과 상세에서 같은 좌측 기능 내비게이션을 유지하고 현재 항목을 표시합니다. 모바일은 선택 메뉴를 접고 펼칠 수 있습니다.
- `/features/<기능>/`, `/en/features/<기능>/`: 출근 자동 기록, 출근 수정, 근무 유형, 시간 표시, 기록, 캘린더, 플러그인, 다우오피스, 반차 인식, 외관, 퇴근 이후 안내, 업데이트. 개요·사용 방법·예시·지원 범위·관련 기능을 제공합니다.
- `/releases/`, `/en/releases/`: 현재 Mac·Windows와 이전 Mac 버전 목록. 총16개 릴리즈 목록·상세 페이지가 같은 내비게이션을 사용하며, 각 목록은 1.5.19·1.5.18·1.5.17·1.5.16·1.5.15·1.5.14·Windows1.5.13 순서의 카드7개를 제공합니다. 각 카드에서 주요 변경점과 다운로드를 바로 제공하며 목록·상세에 릴리즈 내비게이션을 유지합니다.
- `/releases/macos-1.5.19/`, `/releases/macos-1.5.18/`, `/releases/macos-1.5.17/`, `/releases/macos-1.5.16/`, `/releases/macos-1.5.15/`, `/releases/macos-1.5.14/`, `/releases/windows-1.5.13/`와 대응 영어 경로: 주요 변화·개선·지원 범위·기능 설명·공식 다운로드·전체 변경 기록 링크.
- 기존 다운로드·설치·캘린더·FAQ와 overtime 경로, 홈의 예전 앵커를 보존합니다. HTML은 총50개이며 별도 프레임워크 빌드 없이 게시할 수 있습니다.

Mac1.5.19는 부엉이 8상태·휴가 전날 표정, 3열 일반 설정·가이드, 활성 입력 필드의 표준 편집 명령, 테마 윤곽선·설정 톱니바퀴 포커스와 첫 헤더 이미지 캐시를 개선합니다. 1.5.18의 아이콘 렌더링 캐시와 사이드바 행 전체 클릭 영역도 유지합니다. 1.5.17에서 추가한 일반 설정의 ‘메뉴바에 퇴근 예정 시각 표시’도 계속 지원합니다. 기본은 켜짐이며 끄면 선택 단위의 남은 시간만 표시합니다. 선택은 즉시 반영하고 재시작 후에도 유지합니다. 단위 변경은 즉시 반영하고 1초마다, 밀리초는 0.1초마다 갱신합니다. 예정 퇴근 후 옵션을 켜면 시각만, 끄면 ‘퇴근 가능’을 표시합니다. 대기·쉬는 날·연차 표시는 유지합니다. 새 패널·다섯 근무 유형·플러그인 관리·외관은 Mac 전용입니다. Windows1.5.13의 기존 기능과 구분하며 다우오피스 개발자는 손정열로 표시합니다. 출근 기록은 로컬에 저장하지만 선택 캘린더·다우오피스 연결은 해당 서비스의 계정·권한·네트워크를 사용합니다. 예시 화면과 일정은 가상 데이터입니다.

## 검증과 미리보기

```sh
python3 site/check-site.py
node --check site/dist/app.js
node site/tests/interactions.cjs
python3 -m http.server 8765 --bind 127.0.0.1 --directory site/dist
```

검사기는 기존 경로, 사용 방법과 기능/릴리즈의 목록→상세 연결, 설명 구역, 외부 GitHub 사용 문서 링크 금지, 한·영 대응, 로컬 링크·앵커, 한영 홈의 두 직접 다운로드·48페이지 헤더의 명시적 Mac 기본값과 Windows 전환 자산·별도 다운로드 페이지의 대체 파일과 체크섬, 라이선스와 project_id 보존을 확인합니다. 같은 목록·상세 내비게이션의 전체 항목·순서·현재 위치와 카드6개의 변경점 각3개·Mac DMG/ZIP 직접 자산 링크도 검사합니다. 앱 Info.plist의 버전·빌드와 기본 Mac 다운로드/현재 릴리즈 링크를 비교하고, 한영 메뉴바 단위·표시 옵션·즉시 반영·재시작 저장·갱신 주기·퇴근 후 표시 안내도 검사합니다. 이전 릴리즈 10개 본문의 SHA-256을 확인해 설명·다운로드 기록의 변경을 막습니다. 최신 릴리즈는 외관·사이드바 수정, 기존 표시 옵션, 고정 자체 인증서·Sparkle 서명과 Developer ID·공증 미적용, 설치된 앱 교체·권한 대리 승인 미수행 안내를 검사합니다. 캘린더 안내 다섯 곳은 읽기 권한·표시 선택·읽기 전용 새로고침을 선택적 동기화보다 먼저 안내하는지도 검사합니다. Node 회귀 검사는 한·영 8상태 이벤트와 표시 의미, 모바일 메뉴 포커스, 가이드 링크 선택·Escape·반응형 목차의 포커스, Windows/Mac/Android/알 수 없는 OS에서 헤더의 파일과 문구 선택을 확인합니다. DOM 경계의 작은 테스트 더블을 사용하므로 실제 브라우저의 네이티브 키보드·레이아웃 검증을 대신하지 않습니다. 공개 파일의 실제 HTTP 응답과 데스크톱·모바일 화면은 별도 확인합니다. 명세는 [사이트 페이지 명세](../docs/site-detail-pages-spec.md)입니다.

## 게시와 호환 자산

`.openai/hosting.json`의 기존 Sites project_id와 공개 범위를 유지합니다. 검토·병합된 이 디렉터리를 기존 Sites 소스 checkout으로 반영하고 공식 Sites source helper의 commit/push/archive 결과로 같은 프로젝트에 게시합니다. 단기 토큰은 메모리에 보관하고 보조 도구의 숨김 stdin으로만 전달하며 파일·명령 인자·로그에 저장하지 않습니다.

기존 Sites 소스의 `dist/downloads/`, `dist/updates/` 등 과거 호환 자산은 게시 checkout에서 바이트와 해시를 보존합니다. 앱 바이너리·서명 키·개인 기록은 GitHub 사이트 소스에 추가하지 않습니다. 이전 사이트 feed의 자동 이전과 실제 앱 설치 성공은 사이트 게시만으로 주장하지 않습니다. 앱 배포 절차는 [DEPLOYMENT.md](../DEPLOYMENT.md)에서 별도로 관리합니다.
