# 출근 시각 인라인 입력 후속 요구사항

작성일: 2026-10-16 (Asia/Seoul)
상태: 로컬 구현 완료. 검증 결과와 남은 확인은 아래 참조.
기준: PR #42 최종 a55f20dde10886b9c1a86608381c8fb715b01cf6, main 병합 ddedf83b0bfd14f0d47c0cdd7d93b2c3b33112f3.

## 승인된 동작

1. 출근 숫자를 클릭하면 별도 팝업 없이 같은 자리에서 편집한다.
2. 기존 출근 기록이 있으면 그 시각, 없으면 편집 시작 시점의 현재 시각을 기본값으로 표시한다. 편집 중 기본값은 초마다 바뀌지 않는다.
3. 기존 기록이 없는 경우 숫자를 직접 바꾸지 않아도 다른 곳을 클릭하거나 패널을 닫으면 표시 중인 기본 시각을 저장한다. Enter도 저장할 수 있으나 필수는 아니다.
4. 시간은 24시간제 HH:mm, 숫자 네 자리다. 키보드 직접 입력과 각 자릿수 선택 후 −/＋ 조절을 모두 제공한다.
5. 유효한 저장 후 출근·퇴근 예정 시각을 즉시 갱신한다. 저장 버튼·추가 창 없이 처리한다.
6. Escape는 취소한다. 잘못된 입력과 저장 실패는 기존 기록을 보존하고 원인을 표시한다. 근무 유형과 시간의 동시 변경은 원자적으로 처리한다.
7. 기존 컴팩트 카드와 스크롤 없는 레이아웃, 선택 근무 유형 선두 배치, 기존 앱·개인 데이터·개발 기록을 보존한다.

## 기존 검증 규칙과의 관계

현재 근무 유형별 허용 출근 구간, 미래 시각 거부, 자정 변경 거부는 이번 요청만으로 해제하지 않는다. 기본 현재 시각이 기존 허용 구간 밖이면 저장 실패를 알린다. 허용 구간 자체를 바꾸려면 별도 요구사항으로 정한다.

각 숫자 열의 위에 ＋, 아래에 − 버튼을 하나씩 둬 총 8개를 표시한다. 버튼·숫자 중심선을 같은 열로 맞추고 콜론 열에는 버튼을 두지 않는다. 버튼을 누르면 그 열의 자리만 1씩 증감한다. 자리올림·순환은 하지 않는다. 09:59의 분 일의 자리 ＋, 23:59 각 자리 ＋, 00:00 각 자리 − 등 유효 시각을 벗어나는 조작은 비활성화한다. 직접 입력은 수정 중 유효하지 않아도 화면에 유지하고 저장 시 기존 검증으로 거부한다. 네 자리 숫자 또는 HH:mm 붙여넣기도 지원한다.

## 구현 후 확인할 항목

- 출근 기록 없음 → 클릭 시 현재 HH:mm 표시 → 수정 없이 외부 클릭 또는 패널 닫기 → 실제 저장 확인.
- 기존 기록 있음 → 클릭 → 기존 시각 유지, 변경 없이 닫으면 불필요한 쓰기 없음.
- 직접 입력, 네 자리 각각의 선택과 −/＋ 조절, 00/23시·00/59분 경계.
- Enter 없이 수정 저장, Escape 취소, 입력 오류·저장 실패·날짜 변경 시 원본 보존.
- 허용되지 않는 유형 전환과 시각 수정이 함께 발생하면 둘 다 저장하지 않음.
- 저장 성공 시 퇴근 예정 즉시 갱신, 다섯 근무 캡슐과 증감 조작이 카드 밖으로 나가지 않음.
- 격리된 QA 데이터로 검사하며 기존 사용자 기록을 테스트용으로 바꾸지 않음.
