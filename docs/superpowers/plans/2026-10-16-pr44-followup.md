# PR44 리뷰 후속 조치

요청: 리뷰 6건을 검증하고 회귀 검사·최소 수정 후 기존 PR에 푸시한다. 병합·릴리즈·설치 앱 교체는 범위 밖이다.

- Dev 구성: 실제 AppDelegate가 bundle ID에 따라 격리 출근·라우팅·카탈로그·동기화 저장소를 사용한다. 외부 연결·이관·자동 감지·업데이트·로그인 변경을 차단한다. 기존 개발 ID의 기록 경로는 유지한다. 검사: 프로필 경로·플래그, 실제 구성 경계의 readback.
- 라우팅: 비활성화 시 실행 중 fallback만 적용하며 저장된 사용자 선택은 유지한다. 재활성화·재시작 시 복원하고 명시적 연결 변경/등록 해제는 반영한다. 검사: 선택→비활성→재시작→재활성, 다른 기능 선택에도 보존.
- 이관: SQLite 초기화 실패를 미설정으로 취급하지 않는다. 오류 전달·읽기 전용·다음 시작 재시도 검사.
- 붙여넣기: 선택 교체뿐 아니라 기존 숫자 앞/뒤에 전체 시각을 붙여넣는 네 자리 모든 위치 검사.
- 아이콘: 성공 저장 후에만 대체된 앱 생성 복사본 정리. 원본·이전 유효 이미지·실패 원본 보존 검사.
- 다우: 지연 비밀번호 로딩 구성에서 연결 해제→재시작→연결 켜기 시 저장 비밀번호로 재연결 가능. 실제 키체인/계정 대신 fixture 검사.

담당 파일을 분리해 구현하고 최종 고정 diff 독립 검토·관련 검사 후 커밋/푸시한다.

## 최종 로컬 결과

6건 모두 구현·회귀 검사 완료. 네 자리 붙여넣기는 기존 문자/붙여넣기 원문을 추측하는 방식 대신 native field editor의 paste 원문을 전달한다. 기존 숫자와 첫/끝 숫자가 겹치는 1231/12:31, 네 자리·커서 앞/뒤·선택 교체·일반/일반 텍스트 붙여넣기, 포커스·직접 입력·삭제·Return/Escape·접근성을 검사했다. 정상 native 필드가 실제 first responder가 되어 전용 편집기를 얻는 경로도 확인했다.

기존 코드/원인 제거 전 검사 실패(라우팅 보존·이관 오류·다우 저장 비밀번호·아이콘 교체·병합된 붙여넣기 문자열)를 확인하고 수정 후 통과했다. 독립 검토에서 발견한 기본 연결 명시 선택 소실과 저장 실패 뒤 원하는 연결 덮어쓰기까지 수정·검사했다. 최종 고정 diff에서 추가 확정 결함은 없었다.

최종 실행: AfterSixChecks(기존33건+추가 그룹), PluginArchitectureProbe 11그룹, CalendarModelProbe, 실제 번들 production/Dev/QA 프로필 진단, native clock paste probe, release 빌드 모두 exit0. 다우 모델11그룹과 실제 외관 모델(5팔레트/5아이콘/원본/실패/복원/교체 정리)도 작성자 검사 통과. 새 프로필·붙여넣기·외관 probe를 Mac CI 단계에 연결했다. shell 문법·diff 검사 통과.
