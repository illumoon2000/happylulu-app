# PR44 리뷰 후속 조치

요청: 리뷰 6건을 검증하고 회귀 검사·최소 수정 후 기존 PR에 푸시한다. 병합·릴리즈·설치 앱 교체는 범위 밖이다.

- Dev 구성: 실제 AppDelegate가 bundle ID에 따라 격리 출근·라우팅·카탈로그·동기화 저장소를 사용한다. 외부 연결·이관·자동 감지·업데이트·로그인 변경을 차단한다. 기존 개발 ID의 기록 경로는 유지한다. 검사: 프로필 경로·플래그, 실제 구성 경계의 readback.
- 라우팅: 비활성화 시 실행 중 fallback만 적용하며 저장된 사용자 선택은 유지한다. 재활성화·재시작 시 복원하고 명시적 연결 변경/등록 해제는 반영한다. 검사: 선택→비활성→재시작→재활성, 다른 기능 선택에도 보존.
- 이관: SQLite 초기화 실패를 미설정으로 취급하지 않는다. 오류 전달·읽기 전용·다음 시작 재시도 검사.
- 붙여넣기: 선택 교체뿐 아니라 기존 숫자 앞/뒤에 전체 시각을 붙여넣는 네 자리 모든 위치 검사.
- 아이콘: 성공 저장 후에만 대체된 앱 생성 복사본 정리. 원본·이전 유효 이미지·실패 원본 보존 검사.
- 다우: 지연 비밀번호 로딩 구성에서 연결 해제→재시작→연결 켜기 시 저장 비밀번호로 재연결 가능. 실제 키체인/계정 대신 fixture 검사.

담당 파일을 분리해 구현하고 최종 고정 diff 독립 검토·관련 검사 후 커밋/푸시한다.

## 최종 로컬 결과

6건 모두 구현·회귀 검사 완료. 네 자리 붙여넣기는 기존 문자/붙여넣기 원문을 추측하는 방식 대신 native field editor의 paste 원문을 전달한다. 기존 숫자와 첫/끝 숫자가 겹치는 1231/12:31, 네 자리·커서 앞/뒤·선택 교체·일반/일반 텍스트 붙여넣기, 포커스·직접 입력·삭제·Return/Escape·접근성을 검사했다. 정상 native 필드가 실제 first responder가 되어 전용 편집기를 얻는 경로도 확인했다.

기존 코드/원인 제거 전 검사 실패(라우팅 보존·이관 오류·다우 저장 비밀번호·아이콘 교체·병합된 붙여넣기 문자열)를 확인하고 수정 후 통과했다. 독립 검토에서 발견한 기본 연결 명시 선택 소실과 저장 실패 뒤 원하는 연결 덮어쓰기까지 수정·검사했다. 최종 고정 diff에서 추가 확정 결함은 없었다.

최종 실행: AfterSixChecks(기존33건+추가 그룹), PluginArchitectureProbe 11그룹, CalendarModelProbe, 실제 번들 production/Dev/QA 프로필 진단, native clock paste probe, release 빌드 모두 exit0. 다우 모델11그룹과 실제 외관 모델(5팔레트/5아이콘/원본/실패/복원/교체 정리)도 작성자 검사 통과. 새 프로필·붙여넣기·외관 probe를 Mac CI 단계에 연결했다. shell 문법·diff 검사 통과.

증거는 workspace artifacts/happylulu-pr44-followup-20261016/validation에 보존했다. 프로필 CLI는 AppDelegate 생성 전 진단이므로 앱 전체 수명주기 무부작용은 정적 연결 검토와 별개다. 실제 키체인/외부 계정/시스템 클립보드·보이는 UI/설치 앱 교체·서명 패키징은 이번 후속 검증에 포함하지 않았다. 기존 Dev/정식 앱은 교체하지 않았다.

## 추가 이관 경계 (사용자 전달, 2026-10-16)

새 기본 어댑터는 외부 연결을 하지 않지만 이전 builtin은 Mac 일정/반차 어댑터였다. 기존 선택을 그대로 보존하는 것만으로 업그레이드 의미를 보존할 수 없었다. 최초 카탈로그 이관에서만 예전 builtin 및 기존 설치의 암묵적 기본 연결(calendar/halfDay)을 mac-calendar로 변환한다. 휴가 현황 leave와 명시적인 타사 연결은 유지한다. 이전 설치는 출근 저장소 존재 또는 라우팅 파일 존재로 식별하며 신규 설치와 이관 후 사용자가 선택한 builtin은 변환하지 않는다.

검사: 예전 builtin 3종의 선택적 변환, 타사 혼합 연결, 암묵적 기본, 일정만 사용하던 기존 설치, 신규 core-only, 재시작/중복 이관, 기존 카탈로그의 명시적 연결 안 함, 손상 라우팅/이관 저장 실패 원본 보존과 다음 시작 재시도. 이관 전에 실패하면 카탈로그 완료 상태를 쓰지 않으며, 후속 실패는 라우팅 원본을 보존한다. 실제 계정·캘린더를 읽지 않는 fixture로 재현한다.

이 추가 경계는 914c1a4에서 놓친 부분으로, 수정·검증·재검토 결과를 별도로 기록한다.

## 추가 포커스 경계 (부엉이 재검토 댓글 갱신)

텍스트 변경 begin/end delegate를 포커스 신호로 쓰면 타이핑 없이 다음 숫자로 이동한 순간 nil이 남아 PanelView의 다음 run-loop 자동 저장이 편집기를 닫을 수 있다. 앞선 probe는 delegate를 직접 호출해 실제 이벤트 순서를 놓쳤다. field editor/first responder 소유권으로 숫자 간 이동과 전체 편집기 이탈을 구분해야 한다.

검사: 실제 호스팅된 네 자리 편집기에서 첫 자리 타이핑→다른 자리 클릭/Tab→타이핑 없이 다음 run loop에도 편집 유지→바깥으로 포커스 이동 시 한 번 저장. 이전 버그에서 RED를 확인하고 수정 후 GREEN을 확인한다. 원문 붙여넣기·Return/Escape·접근성·숫자 고정 배치를 보존한다. 실제 화면·시스템 클립보드를 조작하지 않는 격리 창/가짜 저장소로 검증한다.

## 추가 2건의 최종 로컬 검증

구버전 builtin 이관과 숫자 간 이동의 조기 저장 모두 재현·수정했다. 이관 회귀는 이전 코드에서 실패한 뒤 최초 변환/타사·leave 보존/명시적 연결 안 함/신규 core-only/재시작/손상·쓰기 실패 원본 복구/실제 수리 후 재시도까지 통과했다. 포커스는 텍스트 변경 알림 대신 field editor responder 소유권으로 추적하고 Tab·Shift-Tab은 네 자리 내 이동, 경계에서는 편집기 이탈로 처리한다.

같은 실제 Panel probe에 이전 helper를 넣으면 ‘다음 자리에 타이핑하기 전에 조기 저장·닫힘’으로 exit133, 수정 helper로는 exit0이었다. 네 자리 간 이동·Tab·Shift-Tab·대기 중 기록 쓰기 없음, 바깥 클릭 때 08:12 한 번 저장, 반복 클릭 시 상태 publish 횟수·파일 inode·mtime 유지 확인. 오프스크린 버튼 AX 진입이 불가능해 임시 Panel 소스의 onAppear에서 실제 beginEditing만 호출하도록 검사 준비 부분을 바꿨다. 실제 body/포커스/다음 run-loop 저장/click-away 코드는 변경하지 않았고 외관·출퇴근·동기화 저장소는 격리했다. 버튼 활성화·보이는 UI·실제 계정 검증으로 확대 해석하지 않는다.

최종 고정 소스에서 AfterSixChecks, 아키텍처12그룹(수리 후 재시도 포함), native clock probe, 실제 Panel focus probe, release 빌드 모두 exit0. 독립 검토 추가 확정 결함 없음. 새 Panel probe를 Mac CI에 연결했다. 로그는 artifacts/happylulu-pr44-followup-20261016/validation/builtin-focus에 보존한다. 설치 앱·개인 데이터·병합·릴리즈는 변경하지 않았다. PR 새 커밋의 CI와 부엉이 재검토는 별도 확인 대상이다.
