# 플러그인 설정 분리와 외관 사용자화

작성일: 2026-10-16 (Asia/Seoul)
상태: 2026-10-16 로컬 구현·Dev 교체·실행 완료. 전체 시각 QA는 UI 도구 중단으로 일부 미검증이며 구현 계획의 실행 결과에 기록한다.
범위: 로컬 구현·개발 앱 업데이트. 기존 정식 앱·개인 데이터·개발 테스트 기록·미커밋 출근 편집 작업을 보존한다. 커밋·push·추가 PR·릴리즈는 별도 요청 전 수행하지 않는다.

## 목표와 화면

출퇴근 기록·수동 시각 수정·근무 유형 선택·근무/휴게 시간·퇴근 계산은 플러그인 없이 작동한다. 캘린더 조회/동기화·다우오피스 연동·캘린더 기반 휴가 인식은 선택 기능으로 내린다. 설정 사이드바는 아래 순서로 배치한다.

- 기본 설정: 일반, 외관, 근무·휴게 시간, 출퇴근 기록, 업데이트
- 플러그인 관리: 설치와 사용 여부 관리
- 가로 구분선
- 설치된 플러그인: 캘린더, 다우오피스, 휴가 자동 인식 등 설치된 항목만 표시

각 플러그인은 관리 목록과 개별 설정 상단에 이름·설명·개발자를 표시한다. 다우오피스 개발자는 사용자가 확인한 **손정열**로 지정한다. 그 외 자체 플러그인은 **HappyLulu contributors**로 표시하며, 다른 개인 이름을 추정하지 않는다. 개발자 정보는 플러그인 메타데이터에서 제공하고 화면 여러 곳에 중복 작성하지 않는다.

## 플러그인 동작과 호환성

첫 버전의 설치는 앱에 포함된 선택 모듈을 등록하는 방식이다. 원격 실행 코드 다운로드나 제3자 플러그인 마켓을 새로 만들지 않는다. 설치·사용 안 함을 구분하고 설치된 항목은 비활성 상태에서도 개별 설정으로 들어갈 수 있다. 비활성화는 기록·인증정보·동기화 중복 방지 정보를 삭제하지 않는다.

- 캘린더: Mac 캘린더 권한·일정 조회·기존 동기화 설정을 소유한다. 사용하지 않으면 이벤트 조회·동기화 타이머·권한 요청을 실행하지 않는다.
- 다우오피스: 회사 계정·일정·휴가 현황과 기존 연결 설정을 소유한다. 비활성화하면 요청/백그라운드 작업을 중지한다.
- 휴가 자동 인식: 연결된 일정에서 현재 지원하는 오전/오후 반차를 인식하는 정책·설정을 소유한다. 수동 지정 유형을 덮어쓰지 않는다. 기존에 없던 일반 연차 자동 판정 규칙을 UI 개편 과정에서 추정해 추가하지 않는다. 기존 지원 범위를 화면에 명시한다.
- 연결 기능 선택은 해당 플러그인 설정 또는 관리의 연결 항목에서 제공한다. 읽을 일정 연결이 없으면 명확히 안내하고 수동 출퇴근 기능을 유지한다.
- 플러그인을 모두 사용하지 않으면 메뉴 패널의 일정은 설치 안내 또는 비표시 상태이며 실제 일정이 있는 것처럼 표시하지 않는다.

기존 설정을 가진 사용자에게 임의로 연결을 끊지 않는다. 기존 동기화/다우오피스/자동 인식이 설정되어 있으면 대응 모듈을 설치·사용 상태로 이관한다. 신규 설치는 출퇴근 기능만 시작한다. 원래 데이터 파일·bundle ID·출근 스키마는 유지하고 선택 모듈 상태는 별도 저장한다. 이관 실패 또는 손상 파일은 덮어쓰지 않고 오류와 읽기 전용 상태를 알린다. 기존 모듈 제외 빌드도 기본 앱으로 실행할 수 있어야 한다.

## 외관: 기본 테마 5개

기본 설정의 **외관**에서 테마·세부 색상·아이콘을 한 화면에 제공한다. 밝은 순백색 면적을 줄이고 차분한 회색 바탕을 기본으로 한다.

| 테마 | 창 배경 | 사이드바 | 강조색 | 본문 |
| --- | --- | --- | --- | --- |
| 소프트 민트 (기본) | #E9EFEB | #E0E7E2 | #286F5D | #26382E |
| 웜 스톤 | #EEEAE3 | #E4DED5 | #786347 | #38342E |
| 블루 그레이 | #E7EDF1 | #DDE5EB | #426780 | #2B3741 |
| 더스티 라벤더 | #EEEAF1 | #E4DEEA | #77608D | #3A3242 |
| 차콜 | #252A2D | #1E2326 | #8CC5B4 | #E0E7E4 |

설정창과 메인 팝오버에 같은 테마를 적용한다. 사이드바·콘텐츠 바탕·주요 카드·강조색·본문색을 각각 ColorPicker와 #RRGGBB 입력으로 수정할 수 있게 한다. 6자리 HEX만 저장하며 유효하지 않은 입력은 기존 색을 보존하고 오류를 표시한다. 사용자 조합은 사용자 지정 상태로 저장하고 테마별 기본값으로 복원할 수 있다. 글자 대비가 낮은 조합은 미리보기에서 경고하되 사용자 선택을 임의로 덮어쓰지 않는다. 포커스·선택·오류는 색상만으로 구분하지 않는다.

## 아이콘: 기본 옵션 5개와 사용자 이미지

기존 웃는 시계 로고의 형태를 유지한다. 기본 옵션은 **기존 아이콘, 민트, 블루, 라벤더, 그라파이트** 다섯 가지다. 사용자가 처음부터 기존 로고를 유지해 달라고 했으므로 임의의 다른 심볼이나 캐릭터로 교체하지 않는다.

- 설정에서 선택 즉시 앱 실행 중 아이콘과 설정·메인 헤더 미리보기에 반영한다.
- 사용자 PNG/JPEG 이미지를 파일 선택창으로 가져와 별도 외관 저장소에 복사하고 원본 사용자 파일은 수정하지 않는다. 잘못된 이미지·읽기 오류·취소는 기존 아이콘을 유지한다. 사용자 이미지에는 선택한 테마 색 필터를 강제하지 않는다.
- 테마와 아이콘 선택은 독립적이다. 기존 아이콘으로 복원할 수 있다.
- 설치된 .app 내부 자산을 덮어써 서명을 훼손하지 않는다. 실행 중 앱/Dock/앱 내부 아이콘의 변경이며, Finder의 설치 번들 아이콘까지 변경하는 기능은 이 범위에서 제외한다. 메뉴바의 작은 템플릿 로고는 명암 가독성을 유지한다.

## 저장과 개발 앱 분리

외관 설정은 출근 데이터와 분리된 Codable 설정으로 저장한다. 유효하지 않은 버전·HEX·이미지 참조는 원본을 보존하고 안전한 기본값으로 표시한다. 저장 실패 시 현재 적용 결과와 저장 실패를 명확히 알리며 성공으로 표시하지 않는다. 상대 파일명만 설정에 보관하고 임의 경로 탐색을 허용하지 않는다.

정식 앱과 Dev는 서로 다른 bundle ID·설정 도메인·외관 이미지 폴더를 쓴다. Dev는 기존 격리 출근 기록을 그대로 사용하고 실제 계정 연결·자동 업데이트·로그인 항목 변경을 실행하지 않는다. 개발 앱을 교체하기 전에 기존 Dev 번들과 기록을 백업하고 교체 전후 기록 SHA-256을 대조한다. 정식 앱과 그 개인 기록은 테스트용으로 읽거나 변경하지 않는다.

## 요구사항별 검증

1. 플러그인 없음: 출퇴근·수동 수정·유형 선택·계산 유지, EventKit/계정/네트워크 호출 없음.
2. 설치·활성화·재시작·비활성화: 사이드바 항목과 상태가 저장값과 일치, 기본 기능 유지, 작업/요청 취소, 오래된 비동기 결과 무시.
3. 기존 연결 이관: 기존 상태·라우팅·동기화 ledger 보존, 재실행 중복 이관 없음, 손상/실패 원본 보존.
4. 개발자 메타데이터: 다우오피스 손정열, 목록과 상세 일치, 미지정 개발자에 임의 개인 이름 생성 안 함.
5. 테마 5개·색상별 편집·초기화·재시작: 실제 설정/팝오버 반영, 잘못된 HEX·저장 실패·손상 설정 보존, 낮은 대비 경고.
6. 아이콘 5개·PNG/JPEG·취소·복원·재시작: 실제 이미지 표시, 원본 파일 및 .app 리소스 보존, 정식/Dev 설정 분리.
7. 기존 시각 편집·플러그인·공유 fixture·캘린더 동기화 회귀 및 앱 빌드. 외부 계정·실제 캘린더 쓰기는 별도 승인 없는 테스트에서 실행하지 않음.
8. 격리 QA 화면: 사이드바 구분선·선택/설치 상태·개발자 표시·5개 외관 옵션·세부 편집·키보드 접근·최소 창 크기. 기존 고정된 출근 숫자 위치 유지.

## 현재 코드에서 바뀔 경계

`SettingsView`/`PluginSettingsView`의 메뉴와 상세 분리, `PluginDescriptor` 개발자 메타데이터, `BundledPlugins`/`PluginManagerModel`의 선택 모듈 상태·생명주기, `DefaultFeatureAdapter`의 Mac 연결 분리, 앱 진입부의 조건부 시작, 독립 외관 모델·저장·설정 뷰를 변경한다. 기존 미커밋 숫자 편집 코드는 삭제하거나 되돌리지 않는다. 이 문서는 설계이며 구현·Dev 교체 완료 증거가 아니다.
