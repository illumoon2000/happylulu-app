## 작은 앱으로, 조금 더 가벼운 하루

- **오늘은 메뉴바에서.** 출근 시각과 퇴근 카운트다운을 확인하고, 이미 출근했다면 시각을 직접 입력하세요.
- **내 근무 방식에 맞게.** 근무·휴게시간, 오전·오후 반차, 다섯 가지 시간 표시와 한국어·영어를 선택하세요.

- **기록은 내 컴퓨터에.** 계정 없이 출퇴근 기능을 사용하고, 필요한 경우 Mac 캘린더만 연결하세요.

HappyLulu는 개인 편의 도구입니다. 회사의 공식 근태 시스템이나 급여·식대 지급 증빙을 대신하지 않습니다.

## 세 단계로 시작하기

1. **받고 옮기세요.** Mac은 DMG를 열어 `Applications` 또는 `~/Applications`로 옮깁니다. Windows는 Desktop Runtime을 설치하고 ZIP 전체를 고정된 폴더에 풉니다. 기존 앱은 먼저 종료하고 같은 위치에서 교체하세요.
2. **웃는 시계를 누르세요.** 메뉴바·트레이에서 오늘을 확인합니다. 이미 출근했다면 출근 시각과 근무 유형을 직접 저장하세요.
3. **내 하루에 맞추세요.** 설정에서 근무·휴게시간, 언어와 시간 표시를 선택합니다. 캘린더는 필요할 때 연결하면 됩니다.

Mac 첫 실행에는 로그인 자동 실행 등록을 시도하며 시스템 승인이 필요할 수 있습니다. 설정에서 끈 선택은 다시 켜지 않습니다. Windows 자동 실행은 설정에서 직접 켭니다. 설치 안내는 위 절차와 [Windows README](../windows/README.md)에 있습니다.

## 메뉴바는 오늘, 사이드바는 설정

Mac의 모든 설정을 **한 창의 사이드바**에서 관리합니다. 캘린더도 같은 창에서 열립니다.

| 화면 | 할 수 있는 일 |
| --- | --- |
| 메뉴바 패널 | 출근·퇴근 예정, 근무 유형 선택, 출근 시각 인라인 수정, 연결된 오늘 일정 |
| 일반 | 언어, 시간 표시 단위, 메뉴바 퇴근 예정 시각 표시, 로그인 자동 실행 |
| 외관 | 기본 테마 5개, 세부 색상, 기본 아이콘 5개·사용자 이미지 |
| 근무 | 근무·휴게시간, 수동 출근, 남은 시간, 오늘 쉬는 날 |
| 출근 기록 | 월별 출근 캘린더, 날짜별 출근 시각·근무 유형·기록 방식, 기록 폴더 열기 |
| 플러그인 관리 | 포함된 선택 모듈 설치·사용 여부, 개발자 표시 |
| 설치된 플러그인 | 캘린더의 일정·동기화, 다우오피스 연결, 휴가 자동 인식 등 모듈별 설정 |
| 업데이트 | 앱 버전, 자동 확인·설치 설정 |

일반 설정에서 시간 표시 단위를 밀리초·초·분·시·시/분 중 고릅니다. 시 모드는 소수점 한 자리까지 올림하므로 90분은 **1.5시간**, 30분은 **0.5시간**입니다. 메뉴바와 근무 설정의 남은 시간 표시에 함께 적용되고 재실행 후에도 유지됩니다. 기본 설정에서는 메뉴바에 퇴근 예정 시각과 남은 시간을 함께 표시합니다(예: `퇴근 18:00 · 1.5시간 남음`). 예정 시각 표시가 켜져 있으면 예정 시각부터 남은 시간 없이 퇴근 예정 시각만 표시합니다.

Mac의 **메뉴바에 퇴근 예정 시각 표시**는 기본으로 켜져 있습니다. 끄면 예정 시각만 숨기고 선택한 단위의 카운트다운은 유지합니다(예: `1.5시간 남음`). 변경은 즉시 반영되고 재실행 후에도 유지됩니다. 꺼진 상태에서 예정 시각에 도달하면 `퇴근 가능`을 표시합니다. 오늘 패널의 퇴근 예정 시각과 근무 기록은 그대로입니다.

## 하루를 계산하는 방법

기본은 **근무 8시간 + 휴게 1시간**입니다. 출근 허용 구간의 마지막 분도 포함합니다.

자동 감지는 로컬 시각 **06:00부터** 시작하며 06:00~07:59:59의 일반·오후 반차 출근을 **같은 날 08:00**로 기록합니다. 예: 06:30 감지 → 08:00 기록 → 기본 퇴근 17:00. 06:00 이전은 제외하고 오전 반차는 기존 13:00~15:00을 유지합니다. 아래 표는 수동 입력·기록 시각의 기존 허용 구간이며 수동 입력에는 보정을 적용하지 않습니다.

| 근무 유형 | 출근 허용 구간 | 기본 예시 |
| --- | --- | --- |
| 일반 | 08:00~10:00 | 09:00 → 18:00 |
| 오후 반차 | 08:00~10:00 | 09:00 → 13:00 |
| 오전 반차 | 13:00~15:00 | 13:00 → 17:00 |

일반 근무는 매달 마지막 금요일에 두 시간 단축합니다. 반차는 휴게 없이 네 시간이며 금요일 단축을 중복 적용하지 않습니다. 공휴일 대체·이월은 하지 않습니다.

Mac은 로그인 항목으로 실행되거나 화면 잠금이 해제될 때 **관측한 첫 유효 시각**을 기록합니다. 이후 잠금 해제는 기존 출근을 덮어쓰지 않으며 수동 수정·쉬는 날을 보존합니다. 일반 수동 실행, 절전 복귀와 세션 활성화만으로 출근을 만들지 않습니다. 앱이 꺼져 있던 동안의 과거 출근을 추정하지 않습니다.

**Mac 1.5.15 build31에서 추가된** 컴팩트 패널과 출근 시각의 HH:mm 직접 수정을 사용할 수 있습니다. 네 자리 숫자를 직접 입력하거나 자리별 +/− 버튼으로 조정합니다. 다른 곳을 누르거나 패널을 닫으면 자동 저장하며 시각만 바꾸면 자동 캘린더 판단과 기존 수동 선택을 유지합니다. 메뉴바 패널 또는 설정 → 근무의 **오늘 근무·휴가**에서 일반근무·오전반차·오후반차·룰루데이·연차/공가를 캘린더 연결 없이 선택합니다. 오늘만 적용하며 선택만으로 출근 시각을 만들지 않습니다. 기존 시각과 유형이 맞지 않으면 저장하지 않습니다.

**룰루데이**는 120분 단축하고 **일반근무의 명시적 선택**은 마지막 금요일에도 0분 단축을 적용합니다. **연차/공가**는 자동 출근과 카운트다운을 멈추되 기존 시각을 보존하며 날짜 상세에서 확인할 수 있습니다. 일반근무·반차를 다시 선택하거나 출근 시각을 저장하면 재개합니다. 연차 상태에서도 아래 ‘오늘 쉬는 날’로 기록을 삭제할 수 있습니다. 과거·미래 날짜 지정, 회사 근태 신청과 휴가 잔여일수 계산은 지원하지 않습니다. Windows 1.5.13에는 이 새 패널·룰루데이·연차/공가·일반근무 단축 해제를 구현하지 않았습니다.

**오늘 쉬는 날**은 확인 후 오늘 기록을 지우고 자동 기록을 멈춥니다. 출근을 직접 입력하면 다시 시작합니다. 집에서 먼저 잠금을 해제하면 그 시각이 기록될 수 있고, 회사 위치나 Wi-Fi는 판별하지 않습니다.

예정 퇴근 30분 이후에는 추가 경과 분, 두 시간 이후에는 식대 시간 기준을 안내합니다. 실제 근무·지급 승인 여부를 판정하지 않습니다.

## 캘린더도, 필요할 때만

Mac의 **설정 → 플러그인 관리**에서 캘린더를 설치·활성화하고 사이드바의 **캘린더** 설정에서 시작합니다. 계정 로그인과 인증정보는 macOS 인터넷 계정이 관리합니다. 양방향 동기화에는 캘린더 **전체 접근**이 필요합니다.

1. 본인 Google·다우오피스 계정을 macOS에 연결합니다.
2. 서로 다른 계정의 테스트 캘린더를 선택합니다.
3. 첫 미리보기에서 작업·보류·충돌을 확인하고 동기화를 시작합니다.

Mac은 일반 표시 알림을 보존하고, 반복 일정은 **과거 30일~미래 365일의 회차별 개별 일정**으로 복사합니다. 초대 회의는 참석자를 재초대하지 않는 개인 복사본으로 만들고 원본을 보호합니다. 자동 삭제·범위 밖 반복 회차·특수 알림은 보류하며 이유를 표시합니다.

일시 중지한 연결은 새 미리보기를 확인한 뒤 다시 시작합니다. macOS 캘린더 저장 성공과 양쪽 웹 서버 반영은 구분하며, 실제 웹 반영은 별도로 확인해야 합니다. [지원 범위·연결·충돌·복구 안내 → CALENDAR.md](../CALENDAR.md)

반차 자동 인식은 접근 가능한 캘린더 제목을 읽습니다. 다른 사람의 공유 일정이 섞이면 수동 근무 유형을 선택하거나 자동 인식을 끄세요. **수동 선택이 자동 판단보다 우선**합니다.

## 내 기록과 업데이트

Mac 1.5.15 build31부터 기존 정식 앱·프로필을 백업하고 실제 앱 교체·재실행과 권한·기록·연결 보존 증거를 확인한 뒤 공개하는 경로를 사용합니다. 검증 결과는 [배포 절차](../DEPLOYMENT.md)와 로컬 배포 receipts에서 구분합니다.

Mac 출퇴근 기록은 `~/Library/Application Support/AfterSix/state.json`에 저장합니다. 앱 식별자와 기존 저장 경로를 유지하며 업데이트를 위해 기록 파일을 지우지 않습니다. 캘린더 연결 상태도 로컬에 보관하고 인증정보는 macOS가 관리합니다. 출퇴근 원격 수집, 키보드·화면 수집은 하지 않습니다.

자동 확인·다운로드·유휴 설치와 고정 자체 서명을 지원합니다. 이전 1.5.11 build27에서 이 Mac 교체·재실행과 기록·연결·권한 보존, 공개 파일·서명 피드 일치를 확인했습니다. 버전별 실제 설치·권한 보존 결과는 배포 검증 기록에서 확인합니다. 외부 Mac과 종전 Site 피드의 자동 이전은 별도 검증입니다. 업데이트가 비활성인 구버전은 활성화 버전으로 한 번 교체해야 합니다. 진행 상황은 [업데이트 안내](../UPDATES.md)와 [이슈 #3](https://github.com/young221718/happylulu-app/issues/3)에서 확인하세요.

Apple Developer ID·공증과 Windows 게시자 서명은 미완료입니다. Intel 실행 파일은 포함하지만 실기기 시험은 남아 있습니다. 회사 관리 기기는 해당 설치 정책을 따르세요. 로그인 출처 기록이 생긴 후 지원하지 않는 구버전으로 되돌리면 원본을 보존한 채 저장이 중지될 수 있으므로 기록을 삭제하지 마세요.

## 개발과 검증

Mac 1.5.15부터 기본 출퇴근 기능과 선택 플러그인을 분리합니다. 설정 → 플러그인 관리에서 설치·사용 여부와 개발자를 확인하고, 사이드바의 모듈별 설정에서 캘린더·휴가 현황·반차 인식의 출처를 선택합니다. 비활성 모듈의 저장된 연결은 재활성화 시 복원하며 명시적인 연결 해제는 유지합니다. API·조회 범위·검증 한계는 [플러그인 안내](PLUGINS.md)를 참고하세요. Windows 1.5.13에는 이 플러그인 기능이 없습니다.

Swift 6와 macOS Command Line Tools를 사용합니다. Windows는 [.NET 빌드 안내](../windows/README.md)를 따릅니다.

```sh
swift run --build-system native AfterSixChecks
swift run --build-system native CalendarSyncChecks
swift run --build-system native CalendarSyncServiceChecks
swift run --build-system native AppPluginChecks
bash scripts/check-daouoffice-model.sh
bash scripts/build-app.sh
```

Mac PR CI는 개인 서명 키 없이 핵심 검사·격리 통합 검사·ad-hoc 앱 패키징·Sparkle 설정을 확인합니다. 로컬 고정 서명, 서명된 업데이트 교체와 Universal 릴리즈 검사는 [UPDATES.md](../UPDATES.md)를 참고하세요.

자동 검사·앱 빌드·실제 기기·웹 서버 반영은 각각 다른 증거입니다. [검증 기록](../VALIDATION.md), [실제 Mac 시험 #4](https://github.com/young221718/happylulu-app/issues/4), [부팅 출근 #13](https://github.com/young221718/happylulu-app/issues/13)에서 완료와 남은 항목을 구분합니다.

변경은 **이슈 → 작업 브랜치 → 검사·독립 검토 → PR → 병합 → 서명·배포 → 실제 응답 확인** 순서로 진행합니다. 개인 기록·키·계정정보와 생성 앱은 Git에 넣지 않습니다.

## 컴팩트 패널 사용 방법

메뉴바에는 선택한 단위의 남은 시간이 표시됩니다. 일반 설정에서 퇴근 예정 시각을 함께 표시할지 선택할 수 있습니다. 메뉴바를 클릭하면 기존 로고, 출근·퇴근 예정, 오늘 일정 최대 3건만 표시하는 작은 패널이 열립니다. 출근 숫자를 클릭하면 같은 자리에서 HH:mm을 직접 수정합니다. Enter 또는 다른 곳을 누르면 저장하고, 잘못된 입력은 원래 기록을 유지하며 오류를 표시합니다. Escape는 취소합니다. 선택된 근무 유형을 누르면 일반근무·오전반차·오후반차·룰루데이·연차/공가가 카드 안에 한 줄로 펼쳐집니다. 선택된 유형이 맨 앞이고 나머지는 기본 순서로 표시됩니다. 룰루데이는 2시간 단축이며 반차와 중복하지 않습니다. 연차/공가는 로컬 통합 휴무 분류로 출근 기록을 보존합니다. 회사 휴가 신청을 대신하지 않습니다.

⚙️ 설정에서 수동 출근 수정, 근무·휴게시간, 기존 추가 시간·식대 기준 안내, 출근 기록과 전체 일정, 종료를 사용할 수 있습니다. 일정 조회 실패는 일정 없음과 구분하며 긴 제목은 생략 표시합니다. 이 패널은 Mac 1.5.15부터 공개 앱에 포함되어 있으며 기존 출퇴근 기록을 사용합니다.

로컬 후속 변경(2026-10-16): 출근 기록이 없을 때 숫자를 누르면 현재 시각을 기본값으로 제시하며, 그대로 다른 곳을 누르거나 패널을 닫아도 저장합니다. HH:mm의 각 자릿수를 클릭해 직접 입력하거나 각 숫자의 위 ＋·아래 − 버튼으로 해당 자리만 조절합니다. 자리올림·순환은 하지 않으며 유효한 시각 범위 밖의 증감은 막습니다. 기존 근무 유형별 허용 시각·미래 거부 규칙은 유지합니다.

## 로컬 개발: 플러그인 설정과 외관 (2026-10-16)

설정 왼쪽은 일반·외관·근무·출퇴근 기록·업데이트와 플러그인 관리로 나뉩니다. 가로선 아래에는 설치한 플러그인만 표시하며, 각 상세 화면에서 연결과 사용 여부를 관리합니다. 다우오피스 개발자는 손정열입니다. 기본 앱은 플러그인 없이 출퇴근 기록·수동 수정·근무 유형·퇴근 계산을 사용할 수 있습니다.

플러그인 설치는 앱에 포함된 선택 기능을 등록하는 방식입니다. 끄면 설정과 기존 기록을 삭제하지 않고 실행을 중지합니다. 휴가 자동 인식은 현재 오전/오후 반차의 명시된 일정 제목을 대상으로 하며 일반 연차를 추정하지 않습니다. 기존 연결이 설정된 앱에서는 대응 플러그인의 상태를 이관합니다.

외관에는 소프트 민트·웜 스톤·블루 그레이·더스티 라벤더·차콜 테마가 있습니다. 창 배경·사이드바·카드·강조·본문을 각각 색상 선택기 또는 HEX로 수정하고 기본값으로 복원할 수 있습니다. 아이콘은 기존 로고와 민트·블루·라벤더·그라파이트 변형 또는 사용자 PNG/JPEG를 선택합니다. 실행 중 아이콘과 앱 내부 미리보기에 반영하며 설치 번들/Finder 아이콘은 유지합니다. 테마와 아이콘은 출퇴근 기록과 별도로 저장됩니다.

### 개발 앱의 격리와 연결 복원

정식 bundle ID `local.chanyoung.AfterSix` 이외의 실행 파일은 개발 프로필을 사용합니다. 출퇴근·플러그인 연결/설치·캘린더 동기화 저장소를 정식 앱과 분리하고 실제 외부 연결·기존 계정 이관·자동 출근 감지·자동 업데이트·로그인 항목 변경을 시작하지 않습니다. 기존 HappyLulu Dev ID는 `HappyLulu Dev/manual-leave-today/state.json` 기록 경로를 유지합니다. `--runtime-profile`은 모델·권한·타이머를 시작하지 않고 선택한 프로필과 경로를 출력합니다. `bash scripts/check-runtime-profile.sh`로 실제 실행 파일을 임시 정식/개발 번들에 넣어 구성을 검사합니다.

플러그인을 잠시 끄면 실행 중에는 기본 연결을 사용하되, 저장된 기능별 선택은 유지합니다. 재시작 후 다시 켜면 원래 연결을 복원합니다. 사용자가 직접 ‘연결 안 함’을 선택하면 그 선택도 유지합니다. 다우오피스의 저장된 비밀번호는 연결을 다시 켤 때 지연 조회하며, 실제 키체인/외부 계정 검증과 fixture 회귀 검사는 별도입니다. 사용자 아이콘을 교체하면 새 설정 저장 성공 후에만 이전 앱 생성 복사본을 정리하며, 가져온 원본 파일과 저장 실패 시 이전 이미지를 보존합니다.

기존 버전에서 ‘HappyLulu 기본’은 Mac 캘린더 일정과 반차 인식을 제공했습니다. 선택 플러그인으로 처음 이관할 때는 그 연결을 ‘캘린더’ 모듈로 옮깁니다. 타사 연결과 휴가 현황의 기본 선택은 유지하고, 이관을 마친 뒤 사용자가 고른 ‘연결 안 함’은 다시 연결하지 않습니다. 신규 설치는 선택 모듈 없는 기본 기능으로 시작합니다.
