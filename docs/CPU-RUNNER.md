# CPU 러너 · 로컬 개발 후보

2026-10-22 승인한 햄스터·토끼·고양이 선택형 메뉴바 플러그인입니다. 현재 공개 Mac 1.5.19에는 포함되지 않습니다. 이번 구현은 Mac용이며 Windows 트레이 구현과 공개 배포는 범위 밖입니다.

## 사용

설정 → 플러그인 → CPU 러너 → 설치 → 플러그인 사용을 켭니다. 동물 선택에서 햄스터·토끼·고양이 중 하나를 고르면 메뉴바에 즉시 반영되고 재실행 후에도 유지됩니다. 메뉴바 동물을 클릭해서도 동물을 바꿀 수 있습니다.

기존 부엉이와 퇴근 시간 옆에 별도의 메뉴바 항목을 추가합니다. 정확한 항목 순서는 macOS 메뉴바 배치에 따릅니다. CPU 사용량이 높아지면 더 빠르게 움직이며 메뉴에 전체 CPU 사용률을 표시합니다. 측정 중이거나 실패하면 0%로 꾸미지 않고 상태를 표시합니다.

플러그인을 끄면 메뉴바 항목·CPU 측정·애니메이션을 종료하고 동물 선택은 보존합니다. 잠자기 중에는 작업을 중단하며 깨어나면 새 기준으로 측정합니다. macOS의 동작 줄이기는 애니메이션을 멈추고, 저전력 모드는 최대 움직임 속도를 낮춥니다.

## 기능·디자인 경계

- **추가 HL-RUNNER-001:** CPU 러너 1개, 동물 3종, 선택 저장, CPU 변화에 따른 움직임.
- **재사용 HL-PLUGIN-001 / HL-UI-011:** 내장 플러그인 목록의 설치와 활성화, 설정 화면. 처음부터 자동 설치하거나 켜지 않습니다.
- **유지 HL-UI-001:** 기존 부엉이 8상태·휴가 전날 장식·퇴근 시각·메뉴바 클릭 동작.
- **유지 HL-PLUGIN-002:** 일정·휴가·반차 연결. CPU 러너는 해당 연결 후보에 나타나지 않습니다.
- **설정 규칙:** 왼쪽 설명, 가운데 현재 동물 예시, 오른쪽 선택. 기존 플러그인 사용 토글을 재사용합니다.
- **그림:** 독자 제작한 AppKit 단색 그림. 26×18pt 고정 영역, 1×/2× 캐시, 동물마다 8프레임. 동물 이름과 CPU 상태를 접근성 이름으로 제공합니다.

## 구현 경계

`CPURunnerIntegration`은 `AppPluginCore`·`AppPluginHost`만 참조합니다. 앱 조립부가 모듈을 등록하며 별도 `NSStatusItem`의 생성·제거는 러너 컨트롤러가 소유합니다. 일정 기능을 제공하지 않는 빈 기능 어댑터를 사용합니다. 동물 설정 키는 `HappyLuluRunnerAnimal`이며 설치·활성화는 기존 플러그인 카탈로그에 저장합니다.

CPU는 로컬 시스템 누적 카운터의 차이를 1초마다 측정합니다. 화면 프레임만 별도 타이머로 바꾸며 매 프레임 설정 화면을 다시 게시하지 않습니다. 상주 측정은 자동 업데이트를 막는 `isRunning` 작업으로 취급하지 않습니다. 네트워크·계정·캘린더 접근을 추가하지 않습니다.

CPU 계산·세 동물 저장·수명주기 검사, 그림 250개 assertion, 기존 출퇴근·플러그인 구조·설정 이동·휴가 전날·자동 업데이트·다우오피스 제거 빌드 검사를 통과했습니다. 설정은 500pt에서 세 동물×한국어/영어×밝음/어두움 12개를 렌더했습니다. CPU 35%는 합성 예시값입니다.

독립 검토에서 정상 CPU 수치 갱신이 일정 화면 재조회를 유발하는 문제를 발견했습니다. 호스트 알림을 활성화·측정 가능 여부 전환으로 제한하고, 서로 다른 정상 CPU 값에서 호스트 알림이 0회인 검사로 실패 재현과 수정 후 통과를 확인했습니다. 수정 후 플러그인 통합 검사를 다시 통과했으며 재검토에서 추가 결함을 찾지 못했습니다.

실제 마우스·키보드 수락 도구는 연결 오류가 발생해 UI 조작 성공으로 기록하지 않았습니다. 이 문서의 구현·자동 검사와 공개 릴리즈·사용자 수락은 별개입니다.

## 2026-10-22 시안 충실도 수정

최초 로컬 후보의 그림은 사용자 검토에서 제안 시안과 머리·몸·다리 비율이 다르다는 지적을 받았습니다. 기능 및 렌더 검사는 디자인 충실도를 보장하지 않습니다. 원안 아래쪽의 단색 캐릭터를 기준으로 큰 머리·통통한 몸·짧은 둥근 발을 다시 그리고, 햄스터의 둥근 귀·토끼의 길고 둥근 귀·고양이의 열린 갈고리 꼬리를 복원했습니다. 색상 시안이나 기존 부엉이를 교체하는 작업은 아닙니다.

디자인 검토에서는 원안·이전 프레임·새 프레임을 같은 높이로 비교하며, 26×18pt 실제 크기와 2× 확대, 밝음·어두움, 8프레임을 따로 확인합니다. 자동 검사와 독립 검토를 마쳐도 최종 외형 수락은 사용자 확인으로 남깁니다.

수정한 최종 소스로 그림 250개 assertion, CPU 러너 회귀 검사, 설정 12개 렌더, 앱 빌드·서명을 다시 통과했습니다. 독립 정적 시각 검토에서 중대한 캐릭터 정체성 이탈을 추가로 찾지 못했지만, 토끼 귀의 각도와 작은 세부는 26pt에 맞춘 단순화가 남습니다. 원안과 픽셀 단위로 동일하다는 뜻은 아닙니다.
