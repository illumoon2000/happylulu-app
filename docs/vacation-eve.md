# Mac 다음 날 휴가 예고

관련 이슈: [#55](https://github.com/young221718/happylulu/issues/55). 기존 연차/공가(HL-DAY-003), 오늘 상태(HL-BASE-002), 메뉴바·패널 캐릭터(HL-ADD-002/003)를 연결하는 표시 기능이다. 휴가 신청·승인·근태 기록을 대신하지 않는다.

## 표시 계약

- 설정에서 선택한 **휴가 현황 연결**의 성공 스냅샷만 사용한다. 새 계정·API·권한·수동 미래 입력을 추가하지 않는다. 연결이 없으면 표시하지 않는다.
- 기존 승인값 `APPROVAL`, 종류 `연차`·`공가`·`연차/공가`만 허용한다. 앞뒤 공백만 제거하며, 부분 문자열이나 일반 일정 제목·잔여 일수로 휴가를 추정하지 않는다. 반차는 대상이 아니다.
- 명시 날짜 목록은 모든 날짜가 유효하고 중복이 없으며 총 일수가 날짜 개수와 같을 때만 하루 전체 휴가로 취급한다. 목록 사이 주말을 채우지 않는다. 기간형은 시작=종료인 하루, 총 1일인 경우만 지원한다. 여러 날의 기간, 날짜와 기간이 섞인 기록, 알 수 없는 일수·종류·상태는 표시하지 않는다.
- 성공 조회 후 **0~900초(양 끝 포함)**인 결과만 사용한다. 이는 기존 15분 조회 주기에 맞춘 상한이다. 조회 실패로 남은 마지막 성공 결과는 상한까지만 유지되고 이후 숨겨진다. 원격 취소는 새 스냅샷에서 관측한 즉시 반영되며, 아직 조회하지 못한 취소의 실시간 확인을 보장하지 않는다.
- ‘내일’은 **휴가 출처 시간대의 다음 양력 날짜**다. 현재 연결의 기본 출처는 Asia/Seoul이며 기기 시간대가 달라도 해당 출처의 날짜를 유지한다. 시간대를 제공하지 않는 출처는 판정하지 않는다.
- 기존 근태 계산의 실제 `departure`에서 600초를 뺀 시점 **이상**이면 표시한다. 화면에 반올림한 남은 분을 사용하지 않는다. 근무 유형에 따른 반차·룰루데이의 퇴근 계산도 그대로 따른다.
- 오늘 출근과 퇴근 예정이 출처 시간대의 같은 날짜에 있어야 한다. 오늘 연차/공가·오늘 쉬는 날·출근 없음·퇴근 예정 없음·자정을 넘는 근무는 예고하지 않는다.
- 예정 퇴근 이후에도 표시할 수 있으며, 출처 시간대의 자정에 종료한다. 출처 해제/교체, 데이터 삭제, 취소/반려/미확정 결과, 오래된 데이터는 기존 모습으로 복귀한다. 시계 변경과 앱 재개에도 현재 시각으로 재평가한다.

## 캐릭터와 우선순위

기존 부엉이 8개 표정의 우선순위는 연차/공가 → 오늘 쉬는 날 → 출근 없음 → 퇴근 예정 시각 경과 → 근무 유형이다. 휴가 예고는 이 상태를 대체하지 않는 의상 속성이다. 휴가·휴무·기록 없음 상태가 의상보다 우선한다.

메뉴바는 기존 26×18 pt template 눈·부리, 패널 헤더는 기존 28×28 pt 컬러 얼굴을 유지한다. 모자와 선글라스는 코드로 겹치며 원본 PNG를 수정하지 않는다. 1×/2× 정상·의상 이미지를 각각 캐시한다. 툴팁과 접근성 이름에 한영으로 ‘내일 연차/공가 / Leave tomorrow’를 추가한다. 기존 근무 유형·카운트다운 텍스트와 저장 데이터는 바꾸지 않는다.

이 기능에 필요한 부엉이 상태·헤더 자산만 포함한다. 테마 기본값, Dock/사용자 선택 아이콘, 설정 레이아웃, 사이트는 변경하지 않는다. Windows 지원은 추가하지 않는다.

## 검증

모든 입력은 합성 fixture이며 실제 계정·개인 일정은 조회하지 않는다.

```sh
swift run --build-system native AfterSixChecks
swift run --build-system native AppPluginChecks
bash scripts/check-vacation-eve.sh
bash scripts/check-vacation-appearance.sh
bash scripts/check-plugin-architecture.sh
bash scripts/check-panel-focus.sh
HAPPY_LULU_SIGNING_IDENTITY=- bash scripts/build-app.sh
```

휴가 판정 검사는 미승인·부분 휴가·불명확한 기간·900초 경계·명시 날짜 간 공백·월말/연말·DST를 포함한다. AppModel 검사는 600초 직전/정각/직후, 취소·출처 전환·자정·현재 상태 우선순위·근무별 퇴근·근태 파일 불변을 검사한다. 외관 검사는 8표정의 정상 이미지, 의상 차이·캐시·1×/2× 경계 및 합성 보드를 확인한다. 릴리즈 검사는 앱에 원본 캐릭터 자산이 빠짐없이 같은 바이트로 들어가는지 확인한다.

fixture 렌더·자동 검사는 실제 데스크톱 메뉴 조작, VoiceOver, 실서비스 조회, 설치·배포 검증과 구분한다. 그 단계는 이 변경의 완료 증거로 주장하지 않는다.
