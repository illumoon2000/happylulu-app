# 사이트 릴리즈와 기능별 상세 페이지

## 2026-10-22 Mac 1.5.19 build 35 릴리스

사용자는 승인된 사이트를 메인에 병합·배포하고 앱과 사이트를 릴리스하도록 요청했다. 현재 배포용 소스는 Mac1.5.19 build35, Windows1.5.13을 안내한다. 1.5.19 한영 상세를 추가해 총50개 경로를 제공하고, 기존 48개 경로·간결한 홈·직접 다운로드·화이트/쿨그레이·부엉이 디자인을 보존한다. 아래 홈 간소화와 2026-10-19의 설계 기록은 이 변경의 기반이다. 소스 검사와 GitHub 자산·CI·사이트 게시·공개 HTTP·실제 앱 설치 증거를 구분한다.

## 2026-10-22 홈 간소화 승인

홈의 대형 다운로드 카드와 설치 3단계 구역을 제거한다. 첫 화면의 Mac·Windows 버튼과 공통 헤더 다운로드는 현재 공개 앱 파일로 직접 연결한다. 첫 화면에는 설치 조건과 내부 사용 안내 링크를 간단히 유지하며, 자세한 설명·대체 파일·체크섬은 기존 다운로드/가이드/릴리즈 페이지에서 제공한다. 모바일과 JavaScript 없는 환경의 두 플랫폼 선택, 기존 홈 앵커와 48개 경로는 보존한다. 아래 2026-10-19 홈의 시작 방법 구역은 이 승인으로 대체되며 앱 기능·공개 릴리즈·배포 범위는 당시 바뀌지 않았다. 현재 릴리스 권한은 위 1.5.19 요청을 따른다.

2026-10-19 사용자 요청에 따라 홈, 기능 목록과 개별 기능, 릴리즈 목록과 버전별 설명을 구분한다. 기존 정적 HTML/CSS/JS와 로고를 재사용하며 계정·백엔드·새 의존성을 추가하지 않는다.

## 완료 조건

- `/features/`, `/en/features/`는 아래 12개 기능의 상세로 연결한다. 각 상세는 개요, 사용 방법, 예시, 지원 범위와 주의점, 관련 기능을 제공한다.
- 기능 경로는 `attendance`, `arrival-time`, `workday-modes`, `countdown`, `history`, `calendar`, `plugins`, `daouoffice`, `leave-recognition`, `appearance`, `overtime`, `updates`이다. 각 경로는 한국어 `/features/<id>/`와 영어 `/en/features/<id>/`를 가진다.
- `/releases/`, `/en/releases/`는 외부로 자동 이동하지 않고 Mac1.5.19 build35, Mac1.5.18 build34, Mac1.5.17 build33, Mac1.5.16 build32, Mac1.5.15 build31, Mac1.5.14 build30, Windows1.5.13 목록을 제공한다. 각 상세는 `/releases/macos-1.5.19/`, `/releases/macos-1.5.18/`, `/releases/macos-1.5.17/`, `/releases/macos-1.5.16/`, `/releases/macos-1.5.15/`, `/releases/macos-1.5.14/`, `/releases/windows-1.5.13/`와 대응 영어 경로를 사용한다.
- 릴리즈 상세는 주요 기능, 개선 사항, 지원 범위, 다운로드를 제공하고 해당 기능 설명과 공식 GitHub 릴리즈에 연결한다. 오래된 전체 변경 기록은 GitHub로 연결한다.
- 홈은 소개·다운로드·핵심 기능·시작 방법에 집중하고 기능 목록과 최신 릴리즈 상세로 이동할 수 있다. 공통 메뉴에 기능·사용 방법·릴리즈·다운로드를 제공한다.
- 기능 목록과 12개 상세는 같은 좌측 기능 내비게이션과 우측 본문 틀을 유지한다. 현재 항목을 표시하고 다른 기능으로 바로 이동할 수 있다. 릴리즈 목록과 상세도 같은 구조를 사용한다. 모바일에서는 기능·릴리즈 선택 메뉴를 접고 펼칠 수 있으며 키보드와 Escape를 지원한다. JavaScript가 없어도 일반 링크 목록을 제공한다.
- 릴리즈 목록·상세 총16개 페이지는 같은 내비게이션을 사용한다. 각 목록은 Mac1.5.19·Mac1.5.18·Mac1.5.17·Mac1.5.16·Mac1.5.15·Mac1.5.14·Windows1.5.13 순서의 카드7개에 변경점 각3개와 정확한 공개 다운로드를 바로 제공한다. 1.5.18·1.5.17·1.5.16·1.5.15·1.5.14·Windows 기존 설명과 자산 링크를 보존한다. 이전 Mac의 최신 배지만 바꾸며 본문의 Windows 최신 버전 문구는 유지한다. Mac은 DMG·ZIP, Windows는 Desktop Runtime 필요 여부가 보이는 ZIP을 제공한다. 상세 상단에도 다운로드를 배치하고 전체 설명·기존 앵커를 유지한다.
- 추가 사용자 지시: 자세한 사용 방법을 GitHub로 보내지 않는다. `/guide/`, `/en/guide/`에서 설치·첫 실행·매일 확인·출근 수정·근무 유형·선택 플러그인·외관·기록·업데이트·문제 해결·플랫폼 차이를 안내한다. 메뉴·카드·footer·기존 도움말 경로의 사용 안내는 사이트 내부 가이드나 개별 기능으로 연결한다. 앱 다운로드·릴리즈 전체 기록·라이선스·소스 링크만 해당 외부 정본을 유지한다.
- 다운로드는 공개 Mac1.5.19 build35와 Windows1.5.13을 가리킨다. Mac 전용 UI·플러그인·외관을 Windows 지원으로 표시하지 않는다. 다우오피스 개발자는 손정열이며 서버 조회와 별도 양방향 캘린더 동기화를 구분한다.
- Mac1.5.19 홈·카운트다운 상세·릴리즈는 1.5.17의 표시 옵션을 유지하며 예정 퇴근 시각과 선택 단위의 남은 시간을 함께 안내한다. 예시는 `퇴근 18:00 · 91분 남음`과 `Leave 18:00 · 91 min left`이다. 밀리초·초·분·시·시/분 변경의 즉시 반영과 1초 갱신(밀리초 0.1초)을 설명한다. 일반의 메뉴바 퇴근 예정 시각 표시 옵션은 기본 켜짐이고 끄면 `91분 남음`/`91 min left`만 표시하며 즉시 반영·재시작 저장한다. 예정 퇴근 후 켜짐은 예정 시각, 꺼짐은 ‘퇴근 가능’/‘Ready to leave’를 표시한다.
- Mac1.5.19 build35 상세는 소문자 브랜드·부엉이8상태, 선택 출처에서 확인한 다음 날 승인된 종일 연차/공가의 휴가 전날 표정(퇴근 예정10분 전부터 출처 기준 날짜가 끝날 때까지, 조건과15분 이내 최신 조회 유지), 일반 설정의 설명/미리보기/조작 3열과 사이드바 가이드, 활성 입력 필드의 실행 취소·다시 실행·잘라내기·복사·붙여넣기·전체 선택, 테마 윤곽선·톱니바퀴 포커스와 첫 헤더 이미지 캐시를 설명한다. 고정 자체 인증서·Sparkle 업데이트 서명과 Developer ID·공증 미적용을 명시하고 설치·권한·실기기 확인의 증거를 대신하지 않는다. 과거1.5.18을 포함한12개 한영 릴리즈 본문과 자산 링크의 SHA-256을 그대로 유지한다.
- 기존 11개 경로, 외부 링크용 앵커, 원래 로고, 라이선스, 프로젝트 크레딧을 보존한다. 출근 기록·계정·실제 일정·키를 사이트에 포함하지 않는다.
- 같은 Sites project_id와 공개 범위를 유지하며 기존 다운로드·서명 피드 자산을 보존한다. 배포 소스와 공개 상태를 구분하고 원격 게시의 실제 승인 범위를 준수한다.

## 요구사항별 검증

1. `python3 site/check-site.py`: 기존 11개 경로와 새 가이드·기능·릴리즈 경로 50개 전체, 목록에서 상세 연결, 사용 안내의 내부 경로, 기능별 5개 설명 구역, 릴리즈별 설명·공식 태그 연결, 언어 대응·제목·로컬 링크/앵커·라이선스·Mac/Windows 자산을 검사한다. 캘린더 안내 다섯 곳은 첫 조회의 읽기 권한·표시 캘린더 선택·읽기 전용 새로고침이 선택적 미리보기·동기화 시작보다 먼저 오는지 검사한다. 앱 Info.plist와 기본 Mac 자산·현재 릴리즈 링크가 일치하는지, 새1.5.19 한영 변경점과12개 과거 본문 SHA-256, 현재 버전 미리보기 캡션, 카드 순서·변경점 각3개·Mac DMG/ZIP, 한영 메뉴바 표시·단위 즉시 반영·갱신 주기·퇴근 후 설명을 검사한다. 새 경로·필수 조회 단계가 없거나 기본 자산이 이전 빌드이고 메뉴바 설명이 예전 동작인 소스에서는 실패해야 한다.
2. `node --check site/dist/app.js`, `git diff --check`: 기존 메뉴·데모 코드 문법과 변경 공백 검사.
3. 로컬 브라우저: 데스크톱과 390px 모바일에서 목록→상세→관련 기능, 릴리즈 목록의 바로 다운로드, 언어 전환, 모바일 선택 메뉴·Escape·키보드 초점과 가로 잘림을 확인한다. 한영 홈의 평일·룰루 예시 각각에서 1280px와 390px 폭의 메뉴바 텍스트와 로고가 겹치지 않는지 실제 경계를 확인한다. 기능 목록과 상세에서 좌측 내비게이션의 위치·순서가 같고 현재 항목만 바뀌는지 확인한다. 직접 주소·새로고침·뒤로 이동을 확인한다.
4. 독립 검토: 실제 앱·문서와 기능 설명/플랫폼/개발자/개인정보 범위를 비교한다. 앱 기능 회귀검사는 사이트 변경의 증거로 반복하지 않는다.
5. 게시 승인 이후: Sites 저장 소스·배포 버전·공개 URL 확인, 대표 기능/릴리즈의 응답과 링크, 기존 다운로드/피드 해시 보존을 확인한다.
