# 컴팩트 메뉴바 UI 명세

2026-10-15 사용자 승인 UX 5차 그림을 로컬 구현한다. 기존 미커밋 #36 작업을 확장하며 기존 앱·개인 데이터·개발용 데이터는 보존한다. 새 커밋·PR·릴리즈는 하지 않는다.

## 메인과 설정

- 기존 로고, 한 개의 메뉴바 팝오버. 메인 364×350pt, 스크롤뷰 없음. 메뉴바에는 퇴근 예정 시각을 24시간제로 표시하고, 퇴근 전에는 설정에서 선택한 단위의 남은 시간을 함께 표시한다. 예정 시각 이후에는 시각만 표시한다.
- 헤더: 기존 앱 아이콘·HappyLulu·별도 ⚙️ 설정 버튼.
- 초록 카드 첫 행은 선택된 근무 유형 캡슐. 누르면 오른쪽으로 다섯 캡슐이 펼쳐진다. 일반근무·오전반차·오후반차·룰루데이·연차/공가. 다섯 캡슐과 포커스는 카드 안에 유지한다. 선택된 유형만 강조하며 실제 저장이 실패하면 선택도 바꾸지 않는다.
- 다음 행은 출근·퇴근 예정, 다음 행은 두 시각. 연차/공가는 퇴근 없음 표시와 기존 출근 기록 보존. 기록 없으면 시각을 꾸며내지 않고 ‘—’ 표시.
- 출근 시각/빈 시각을 누르면 같은 자리의 HH:mm 입력칸. 기존 오늘 날짜·시간 창·미래 거부·캘린더/수동 우선 규칙을 유지한다. 자정 경과 시 다시 열도록 거부한다. Enter, 다른 곳 클릭 또는 패널 닫기로 저장하고 퇴근 시각을 재계산한다. 잘못된 입력은 원래 기록을 유지하고 인라인 오류를 표시한다. Escape는 취소한다. 선택된 근무 유형이 맨 앞이며 나머지 네 항목은 기본 순서를 유지한다.
- 오늘 일정은 선택된 연결에서 조회한 오늘 겹치는 일정 중 최대 3건, 시간·제목 한 줄. 종일 우선, 시작 시각 순. 자정에 끝난 전날 일정 제외, 여러 날 일정·자정·DST·조회 오류·결과 없음 구분. 더 많은 건은 ‘+N건’ 버튼으로 기존 전체 설정 캘린더에 연결한다. 오류 상세·수동 수정은 별도 sheet/설정에서 확인하고 메인에는 스크롤을 만들지 않는다.
- 설정창에 근무시간·수동 수정·추가 시간/식대 안내·출근 기록·전체 일정·업데이트·종료 등 기존 기능 접근을 유지한다. 메뉴바에 중복 status item을 새로 만들지 않는다.

## 근무 계산과 보존

- 일반근무·오전/오후 반차·연차/공가는 기존 #36 의미를 유지한다. 연차/공가는 로컬의 통합 휴무 분류이며 회사 휴가 신청·종류별 잔여일수를 처리하지 않는다.
- 룰루데이 수동 선택은 정상 근무 시간+휴게에서 120분 단축한다. 일반근무 수동 선택은 자동 마지막 금요일 단축을 해제할 수 있다. 반차는 기존 네 시간으로 단축과 중복하지 않는다.
- 별도 선택이 없으면 마지막 금요일 자동 인식과 기존 수동 출근 규칙을 유지한다. 명시적인 단축 0/120분 override는 Arrival의 optional `earlyLeaveOverrideMinutes`에 기록한다. 오래된 데이터의 누락 필드는 nil이며 기존 자동 계산이다. 유효하지 않은 override는 StateStore에서 거부하고 원본 파일을 보존한다.
- 시각·출처·시간대는 선택만으로 만들거나 바꾸지 않는다. 연차 선택은 기존 arrival을 그대로 보존한다. 개발 앱은 기존 고유 bundle ID와 별도 저장소를 유지하고 외부 연결·자동 업데이트·login/unlock 등록을 실행하지 않는다.

## 검사

1. 새 룰루 선택→평일 09시 출근=16시 퇴근, 일반 복귀=18시, 금요일 자동=16시, 명시 일반=18시. pending 선택·수동 입력·재시작·추가시간 기준과 일치. 반차/연차 전환 및 시각·출처·시간대 보존.
2. legacy JSON·새 override roundtrip·잘못된 override 파일의 거부/바이트 보존. 기존 33검사+공유 fixture20건.
3. 오늘 일정 0/3/5건, 종일·겹침·정확한 자정·DST, source 변경/취소·오류와 empty 상태 검사.
4. 격리 AppModel에서 메뉴바 시각·자동 근무유형·수동 시각 재계산·실패 원자성 검사. 실제 UI에서 캡슐 접기/펼치기·5항목 경계·시각 인라인 수정·클릭 외부 자동 저장·설정 분리·스크롤 없음 확인.
5. 기존 소스/개발 앱의 복구 사본을 남기고 개발 앱만 교체. 개발 기록은 값 출력 없이 SHA256 대조. 기존 개인 저장소를 읽거나 실행하지 않는다.
