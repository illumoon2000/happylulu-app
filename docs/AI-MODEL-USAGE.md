# AI 모델 사용량 플러그인

설정 → 일반에서 **사용량 보기**를 켜면 AI 사용량 플러그인이 설치되고 활성화됩니다. 기본값은 꺼짐입니다. 플러그인 관리에서도 같은 기능을 켜고 끌 수 있습니다.

현재 지원 대상은 Codex의 ChatGPT 계정입니다. 메뉴바에 `Codex 72%`처럼 주간 잔여 한도를 표시합니다. 메뉴 패널의 사용량 행 또는 일반 설정의 **사용량 설정**을 누르면 상세 설정을 엽니다.

- 주간 잔여량, 초기화 시각, 마지막 성공한 조회 시각
- 최근 최대 1시간의 관측값으로 계산한 시간당 소모율
- 자동 갱신 1·5·10·15·30분, 기본 5분과 수동 새로고침
- 라벨 표시 방식 및 잔여량 부족 알림

사용량은 주간 한도의 비율입니다. 모델별 토큰 수·요청 수·API 비용을 의미하지 않습니다. 시간당 소모율은 최소 1분 간격의 관측 두 개가 필요하며, 데이터 부족은 `—`로 표시합니다. 분당 소모율은 표시하지 않습니다.

기존 Codex 로그인을 자동으로 사용합니다. 연결이 필요하면 플러그인 설정의 **Codex 연결 → ChatGPT로 로그인**을 누릅니다. 다른 계정으로 로그인하면 Codex CLI의 계정도 변경됩니다. API 키 로그인에는 ChatGPT 주간 한도가 없습니다. 실행 파일을 찾지 못하면 연결 설정에서 선택할 수 있습니다.

**사용량 보기**를 끄면 타이머·로그인 대기·진행 중인 사용량 조회를 중단하고 표시를 제거합니다. 설정과 최근 관측 기록은 보존합니다. 조회가 실패하면 마지막 값을 이전 조회 값으로 표시하고, 로그아웃·한도 미제공 상태에서는 미확인 값으로 표시합니다. 초기화 이후 잔여량을 임의로 100%로 만들지 않습니다.

비밀번호와 인증 토큰은 플러그인이 직접 저장하지 않습니다. Codex가 인증을 관리하며 사용량 조회는 모델 추론을 실행하지 않습니다. 계정 식별은 해시로 보관하고, 최근 2시간의 관측만 로컬에 저장합니다. 계정·초기화 주기 변경, 긴 공백, 서버 보정은 분석 구간을 나눕니다.

## 외관

macOS 26 이상에서 순정 리퀴드 글래스 테마를 선택하면 사용량 설정도 공통 설정 창의 시스템 색상·라이트/다크 모드·기본 컨트롤을 따릅니다. 사용량 행이 추가되면 메뉴 패널은 높이를 늘리고 메뉴바 항목 아래 위치를 유지합니다. 행을 누르면 사용량 플러그인 설정으로 이동하며, 더 보기 메뉴의 설정·종료 기능도 유지합니다.

플러그인의 SwiftUI 화면은 앱 전용 글래스 코드에 의존하지 않습니다. 창·탐색·재질은 호스트가 처리하고, 미지원 macOS와 기존 테마는 기존 외관을 사용합니다.

## 구현 경계

- `AIUsagePlugin`: 제공자 어댑터, Codex RPC·로그인, 한도 해석과 이력 분석
- `AIUsageIntegration`: 플러그인 수명주기·설정·알림과 SwiftUI 상세 화면
- 공통 앱: 제공자가 등록한 메뉴 상태와 설정 화면만 사용하며 Codex 통신을 직접 수행하지 않음

`HAPPY_LULU_DISABLE_AI_USAGE=1`로 빌드하거나 두 플러그인 소스 디렉터리를 제거하면 기본 앱을 사용량 플러그인 없이 빌드할 수 있습니다. 출근 기록·캘린더 기능과 번들 식별자는 유지합니다. 이 구현은 macOS용이며 Windows 앱에는 연결하지 않습니다.

## 검증

```sh
swift test --build-system native --filter AIUsageTests
bash scripts/check-plugin-architecture.sh
bash scripts/check-ai-usage-ui.sh
```

UI 검사는 별도 앱 식별자와 합성 사용량 72%로 기존 테마·순정 테마의 밝은/어두운 설정 및 390pt 패널, 사용량 행의 설정 이동, 설정·종료 메뉴를 검사합니다. 실제 계정 로그인·알림 권한·실제 상태 항목 클릭 검증과 구분합니다.

`HAPPY_LULU_USAGE_LIVE=1 HAPPY_LULU_USAGE_EVIDENCE=/tmp/happylulu-usage-ui bash scripts/check-ai-usage-ui.sh`로 실행하면 기존 화면 캡처 권한이 있을 때 테스트 창만 WindowServer로 캡처합니다. 개인 화면이나 실제 사용량은 캡처하지 않고 새 권한을 요청하지 않습니다.
