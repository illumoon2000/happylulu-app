# AI 사용량 표시

- 모드: Operate. 기존 HappyLulu 설정과 메뉴 패널의 작은 확장이다.
- 일반 설정에서 `사용량 보기`를 켜면 사용량 플러그인이 설치·활성화된다. 기본값은 꺼짐이다.
- 메뉴바의 출퇴근 표시는 유지하며 사용량 상태를 덧붙인다. 메뉴 패널의 사용량 행을 누르면 해당 플러그인 설정을 연다.
- 상세 화면은 주간 잔여량, 초기화 시각, 시간당 소모율, 마지막 조회 순서로 표시한다. 미확인 값은 `—`, 이전 값은 상태 문구로 구분한다.
- 기존 팔레트·시스템 글꼴·네이티브 컨트롤·설정 그룹을 사용한다. 새 그래프나 장식은 추가하지 않는다.
- 어두운/밝은 테마의 실제 설정·패널을 격리된 예시 데이터로 캡처한다. 예시 수치는 실계정 조회 증거가 아니다.
