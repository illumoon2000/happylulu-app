# HappyLulu for Windows 1.5.13

2026-10-13 · 예정 퇴근 이후 시간 기준과 기능 설명 명시

- 기존 예정 퇴근 30분 뒤 추가 경과 분 표시와 예정 퇴근+2시간 식대 참고 기준을 유지합니다.
- 계산·오늘 화면·트레이에서 30분·120분 기준값을 명시적인 상수로 공유합니다.
- SPEC.md와 공식 사이트의 한국어·영어 기능 설명에 표시 시점, 예시와 미표시 조건을 명시합니다.

실제 근무 여부나 식대 지급 승인을 판단하지 않습니다. 기존 자동 출근·수동 입력·반차·쉬는 날·기록·표시 설정과 저장 형식은 유지합니다. 실제 Windows GUI·잠금 해제·로그인·설치와 코드 서명은 별도 미검증입니다.

Windows 10/11 x64용 포터블 ZIP 두 종류를 제공합니다. runtime-required ZIP은 .NET 10 Desktop Runtime x64가 필요하며 self-contained ZIP은 런타임을 포함합니다.

# HappyLulu for Windows 1.5.12

2026-10-12 · 06시 자동 출근 감지와 08시 보정

- 앱 실행 중 SessionUnlock을 로컬 시각 06:00부터 감지하고 08:00 이전의 일반 출근은 같은 날 08:00로 기록합니다. 이후 잠금 해제는 첫 기록을 유지합니다.
- 06:00 이전 제외와 08:00 이후 기존 시간대, 오전 반차 13:00~15:00 규칙을 유지합니다. 오후 반차는 기존처럼 직접 선택합니다.
- 수동 입력은 자동 보정하지 않으며 기존 허용 시간·미래 시각 거부·기록 보호·쉬는 날을 유지합니다.
- Mac과 같은 1.5.12 버전으로 정렬했습니다. Windows의 로그인 시 출근 감지·캘린더 동기화·앱 자체 자동 업데이트는 추가하지 않았습니다.

Windows 10/11 x64용 포터블 ZIP 두 종류를 제공합니다. runtime-required ZIP은 .NET 10 Desktop Runtime x64가 필요하며 self-contained ZIP은 런타임을 포함합니다. Windows 코드 서명·실제 사용자 GUI·잠금 해제·로그인 시험은 별도 미검증입니다. 공개 CI의 검사·빌드가 실제 사용자 세션을 대신하지 않습니다.

# HappyLulu for Windows 1.2.1 (배포 후보 · 미게시)

2026-10-07 · 시간 단위 남은 시간 표시 수정 · 아직 공개 배포 전

- 시간 단위 표시를 0.1시간(6분)씩 올림합니다. 90분은 1.5시간, 30분은 0.5시간으로 표시하며 정수 시간의 `.0`은 생략합니다.
- 남은 시간이 양수면 최소 0.1시간, 0 이하이면 0시간으로 표시합니다. 한국어·영어 모두 소수점에 `.`을 사용합니다.
- 기존 시간 단위 설정과 저장된 기록은 그대로 읽습니다. 다른 표시 단위와 출퇴근·야근 계산 기준은 바뀌지 않습니다.

# HappyLulu for Windows 1.0.0

2026-10-02 · 첫 Windows 배포 · Windows 10/11 x64

## 이번 버전

- 알림 영역 트레이에서 오늘 출근·퇴근 예정과 남은 시간을 확인합니다.
- 설정은 별도 창에서 관리하며 근무·휴게시간과 최근 기록을 제공합니다.
- 앱 실행 중 실제 세션 잠금 해제의 첫 유효 출근만 기록합니다. 수동 입력·수정과 오늘 쉬는 날을 지원합니다.
- 일반 근무 09:00→18:00, 오후 반차09:00→13:00, 오전 반차13:00→17:00. 마지막 금요일의 일반 근무는 2시간 단축하고 반차와 중복 적용하지 않습니다.
- 시스템 언어·한국어·영어 선택을 저장하고 열린 화면에 반영합니다.
- 자동 실행은 사용자가 설정에서 직접 선택하며 사용자별 중복 실행을 방지합니다.
- 출퇴근 기록은 `%LOCALAPPDATA%\HappyLulu\state.json`에 로컬로 보관합니다.

## 설치와 업데이트

런타임 포함 ZIP은 압축을 풀어 HappyLulu.exe를 실행합니다. 사이트의 작은 런타임 별도 ZIP은 **.NET 10 Desktop Runtime x64** 설치가 필요합니다. 자동 실행을 사용할 때는 고정된 폴더에 두고, 위치를 옮기면 다시 설정하세요. 업데이트 전에는 트레이에서 종료한 뒤 파일을 교체합니다.

## 지원 범위와 검증

캘린더 동기화·캘린더 반차 자동 인식과 앱 자체 자동 업데이트는 이번 Windows판에 없습니다. 게시자 서명은 완료하지 않았습니다. 회사 설치 정책을 따릅니다.

코어22검사, Mac의 win-x64 교차 빌드, 실제 Windows CI의 두 배포본 빌드·ZIP 생성은 통과했습니다. 실제 사용자 Windows 세션의 트레이·잠금 해제·로그인 자동 실행·언어 전환은 [내부 시험 #7](https://github.com/young221718/happylulu-app/issues/7)에서 확인해야 합니다.
